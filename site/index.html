ScanDrix CLI

Autonomous AI code review, AST security assurance, and bundled skills for Claude Code, Cursor, Codex, Windsurf, and AGY agents from a single high-performance Go binary.

Installation

The installer downloads the native static binary, places scandrix in your PATH, and synchronizes bundled skills into detected local agent roots.

Alternative: brew install scandrix/tap/scandrix or go install github.com/scandrix/backend/cmd/scandrix@latest.

Core Commands

scandrix review Code Review & Security Gate

Review local git changes, staged diffs, or PR branches. Executes AST security rules, detects regressions, and outputs prompt-friendly JSON for coding agents.

--prompt-only --staged --commit <sha> --branch <name> --fast --agent --fix
scandrix pr suggestions PR Triage & Remediation

Fetch and triage AI code review suggestions from remote pull requests, with line-accurate AST diff patches and automated verification.

--pr-url <url> --pr-number <n> --repo-id <id> --fields <csv> --apply --agent
scandrix trace Risk Vector & Call-Path

Deep dependency vulnerability graphing and AST taint tracing. Pinpoints exact execution paths from untrusted input to sensitive database or system sinks.

<paths...> --format json pin <id> forget <id> ui
scandrix skills install Agent Ecosystem

Synchronize bundled ScanDrix agent skills into local IDE and coding agent configuration directories (Claude Code, Cursor, Codex, Windsurf, AGY).

install sync resync uninstall prompt --dry-run
scandrix config centralized Enterprise Compliance

Manage centralized configuration and synchronize organization-wide security rules and compliance policies across engineering teams.

status init sync disable remote add remote list

How It Works

1

Single Static Binary — Zero Dependencies

Compiled in Go with zero external runtime requirements (no Node.js or Python runtime required). Instant cold-start with minimal memory overhead.

2

Autonomous Auto-Remediation (--fix)

Produces line-accurate diff replacements and applies verified security and style fixes directly to source files.

3

Interactive 3-Panel TUI Cockpit

Built on Bubbletea with syntax-highlighted diffs, instant finding navigation, and one-click patch application.

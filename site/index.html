ScanDrix CLI

Autonomous AI code review, OWASP security assurance, and bundled skills for Claude Code, Cursor, Codex, and AGY agents from a single high-performance Go binary.

Quick Install

Installs the self-contained scandrix binary globally and synchronizes bundled agent skills into detected local agent roots.

Alternative: go install github.com/scandrix/backend/cmd/cli@latest or run scandrix skills install.

Core Commands

scandrix review Local Code Review

Review workspace changes, enforce security baselines, gate commits/merges, and optionally emit prompt-friendly markdown or auto-apply diff patches.

--prompt-only --staged --fix --branch <name> --commit <sha> --fast --heavy --agent --fields <csv>
scandrix pr suggestions Remote PR Resolver

Fetch and triage AI review suggestions from remote pull requests, with structured output for agent auto-resolution.

--pr-url <url> --pr-number <n> --fields <csv> --agent
scandrix pr business-validation Acceptance Criteria Gate

Validate local code implementations against project management acceptance criteria (Jira, Linear, GitHub Issues) before opening PRs.

--task-id <id> --task-url <url> --staged --branch <name>
scandrix trace Decision Memory

Query, pin, or forget architectural tradeoffs and decision context across codebase paths before modifying unfamiliar packages.

<paths...> --format json pin <id> forget <id> ui
scandrix skills install Agent Ecosystem

Synchronize bundled ScanDrix agent skills into local IDE and coding agent configuration directories.

install sync resync uninstall prompt --dry-run
scandrix config centralized Enterprise Compliance

Manage centralized configuration and synchronize organization-wide security rules across all engineering teams.

status init sync disable remote add remote list

Engine Architecture

1

Single Static Binary — Zero Dependencies

2

Autonomous Auto-Remediation (--fix)

Produces line-accurate diff replacements and applies verified security and style fixes directly to source files.

3

Interactive 3-Panel TUI Cockpit

Built on Bubbletea with syntax-highlighted diffs, instant finding navigation, and one-click patch application.
